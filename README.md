# AeroTrip Studio — Smart Weather, Travel Itinerary & Geospatial Map Dashboard

Proyek portofolio Software Engineering yang memadukan 60% Modern Framework (React + Vite + Tailwind CSS) dan 40% HTML5/CSS3/Vanilla JS Murni menggunakan alur kerja Kiro AI (Spec-Driven Development) dan Git.

## Cakupan 12 Destinasi Jawa-Bali
Jakarta & Sekitarnya, Bandung, Semarang, Yogya, Solo, Kediri, Malang, Surabaya, Jember, Canggu, Ubud, dan Denpasar.

## Cara Menjalankan Proyek Secara Lokal
1. Jalankan `npm install`
2. Jalankan `npm run dev`
